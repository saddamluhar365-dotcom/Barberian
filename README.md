# Barberian

Minimal API-first agent foundation.

## Run

```powershell
python app.py
```

Open `http://localhost:10000`.

## Chat commands

- `add GitHub MCP`
- `add research skill`
- `list MCP`
- `list skills`
- `disable GitHub MCP`

The current foundation validates a small approved integration catalog. More providers, MCP sources, Skills, research, media, storage, and durable execution will be added in later phases without unnecessary complexity.
